## 🔬 Featured Research & Projects

### 🧠 [AGENTRUN — Agentic RAG Researcher](https://github.com/alyssa2ai/agentic-rag-researcher)

A stateful, evidence-aware research agent that plans queries, searches semantic memory and the web, verifies retrieved evidence, performs bounded re-research, and produces grounded answers with citations and provenance.

**Research focus:** agent reliability, retrieval, evidence verification, provenance, failure analysis, and evaluation.

**Built with:** Python, LangChain, ChromaDB, Hugging Face, Groq, Streamlit

**Highlights**

* Planner → Executor → Verifier → Synthesizer architecture
* Semantic-memory relevance gating
* Web + Wikipedia retrieval with graceful degradation
* Evidence quality, contradiction, and gap detection
* Bounded research loops
* Structured execution traces and provenance
* Truthful result states for insufficient or degraded evidence
* Benchmark/evaluation scaffolding
* End-to-end test suite

> **Current direction:** expanding AGENTRUN into a more rigorous study of agent reliability, benchmarking, ablations, and failure modes.

### 🌾 [CropScout AIoT](https://github.com/alyssa2ai/CropScoutAIoT)

An autonomous agricultural rover combining **computer vision, embedded systems, and IoT** for plant disease detection.

* ESP32-CAM based vision system
* Custom CNN for leaf-disease classification
* 38 disease classes
* Real-time monitoring and dashboard
* Multilingual interface: English / Hindi / Kannada

**Research interest:** robust computer vision under real-world distribution shift.
