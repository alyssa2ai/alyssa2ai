## 📄 Featured Publication

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22346935.svg)](https://doi.org/10.5281/zenodo.22346935)

### [AGENTRUN: Failure-Driven QLoRA Specialization for Multi-Tool Agent Behavior](https://github.com/alyssa2ai/AGENTRUN)
*A Controlled Case Study of Fine-Tuning Regression, Trace-Level Diagnosis, and Targeted Recovery*

- **The Finding:** Discovered that QLoRA fine-tuning on 35 trajectories *regressed* performance (95.7% → 78.3%) on a 23-task multi-tool benchmark.
- **The Contribution:** Formalized a 5-category trace-level failure taxonomy (Parser, Omission, Budget, Semantic, Baseline) to diagnose why agents fail.
- **The Hook:** Built and integrated an **MCP (Model Context Protocol) client** — a ~1-year-old protocol that very few undergrads have hands-on experience with.
- **Status:** Preprint on Zenodo. *Currently expanding to include ReAct baselines and a 150-task evaluation (V2 in progress).*
